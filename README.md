# Whiteboard TV

面向会议室、课堂和家庭共创的电视协作白板。电视展示完整画布；参与者扫码后，在自己的手机或 Pad 上独立编辑，电视实时显示指针、笔迹和对象操作。

**当前状态：已实现 M1 浏览器协作实验版，尚无电视 APK。** 支持画笔/荧光笔/整条擦除、独立镜头、真实指针与笔迹过程、电视只读总览、保存和重连。M1 的真实设备与容量验证仍待完成，性能指标仍为验收目标。

## 产品约定

- 同一份共享内容，每台设备拥有独立视角。
- 电视默认总览全部内容，主持人可临时聚焦，随时返回总览。
- 手写保留为笔迹；手写转文字属于后续增强。
- 首版优先验证 Android TV / 安卓盒子展示与移动浏览器编辑；具体电视型号待确认。
- 参考飞书画板的协作体验，自主设计视觉与交互。

## 推进方式

先完成 M1 技术验证，再实现 M2 多人协作闭环，之后扩展文字、贴图、脑图与电视安装包。每个阶段交付可运行版本、验证记录和文档更新。关键能力先经过真实设备验证，再扩大范围。

当前工程包含 apps/web、apps/server 与 packages/board-core；Android TV 外壳和完整房间管理尚未实现。

## 本地运行

需要 Node.js 22.12+：

```sh
npm ci
npm run dev
```

打开 http://127.0.0.1:5173，创建白板，通过“邀请加入”复制编辑链接，在另一窗口加入；“电视视图”打开只读总览。也可以 npm run build 后 npm start，访问 http://127.0.0.1:8787。

本机二维码不能直接供手机访问；跨设备试用需要可达的局域网地址。当前实验版没有限时邀请、主持人管理、文字、图片或脑图功能，不应直接部署到公网。详见 [运行与限制](docs/08-m1-implementation.md)。

验证命令：npm test、npm run build、npm run test:e2e。浏览器测试需要先安装 Playwright Chromium。
