# Whiteboard TV

面向会议室、课堂和家庭共创的电视协作白板。电视展示完整画布；参与者扫码后，在自己的手机或 Pad 上独立编辑，电视实时显示指针、笔迹和对象操作。

**当前状态：产品与研发规划阶段，尚无可运行 APP。** 仓库原始内容只有标题。2026-11-23 建立第一版开发基线，所有工期和性能指标均为计划或验收目标。

## 产品约定

- 同一份共享内容，每台设备拥有独立视角。
- 电视默认总览全部内容，主持人可临时聚焦，随时返回总览。
- 手写保留为笔迹；手写转文字属于后续增强。
- 首版优先验证 Android TV / 安卓盒子展示与移动浏览器编辑；具体电视型号待确认。
- 参考飞书画板的协作体验，自主设计视觉与交互。

## 推进方式

先完成 M1 技术验证，再实现 M2 多人协作闭环，之后扩展文字、贴图、脑图与电视安装包。每个阶段交付可运行版本、验证记录和文档更新。关键能力先经过真实设备验证，再扩大范围。

代码预计按 apps/web、apps/server、apps/android-tv、packages/board-core、packages/protocol、packages/ui 组织；这些目录是规划，并非现有实现。部署与运行命令在可执行工程建立后添加，避免提供无效命令。
