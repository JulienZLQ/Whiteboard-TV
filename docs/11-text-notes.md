# M3 第一批：文字、便签与对象操作

更新：2026-11-23。此阶段在原有协作画布上增加内容对象；M3 尚未全部完成。

## 使用方式

- 点击「添加文字」或「添加便签」，再点击画布选择放置位置。弹窗支持中文、多行与最多 500 个 UTF-16 代码单元。
- 输入时其他编辑端与电视可看到临时内容；点击「保存内容」后落盘。「取消」只撤回当前草稿。
- 保存后自动切换到「选择对象」。拖动文字/便签可以移动；选中后「编辑内容」「删除对象」可继续操作。桌面双击对象编辑，V 切换选择，Delete/Backspace 删除，Escape 取消选中。
- 双指缩放/移动会取消未提交的放置或拖动。画笔、荧光笔和整条擦除继续保留；笔迹暂不支持选择移动。
- 手机工具栏改为两行，保留七个主工具和三种颜色；桌面为纵向工具栏。
- 电视总览同时包含笔迹、文字、便签以及操作预览；关注成员仍只改变当前电视镜头。

文字对象宽 320 世界单位、字号 24，按内容自动增加高度；便签至少高 200、固定暖黄色背景。文字使用所选笔色。当前支持普通文本，尚不支持富文本、改变字号、缩放对象、多选或调整图层。

## 协作与存储

新增对象集合 objects，结构为 id、kind（text/note）、x、y、text、color。新增 create-object、update-object、delete-object 持久命令及 object-preview 临时通道；已有协议版本 1 的 hello 与笔迹命令继续使用。升级服务后需刷新所有网页/电视页面，旧页面无法渲染新对象。

- update-object 每次只提交文字或一对位置坐标，因此拖动与改字不会覆盖对方字段。同一字段同时修改，以服务端最后持久化的值为准；不是逐字 CRDT 合并。
- 服务端串行校验、候选文档落盘成功后才广播并确认；对象命令记录 mutationId，断线重发不会把较新的修改倒退。删除墓碑阻止旧创建/修改使对象复活。
- object-preview 不落盘，最长保留 5 秒，输入弹窗每 2 秒续期。取消、断开、移除成员或结束会话后清除预览；已删除对象的旧预览不显示。
- 本地持久操作沿用 sessionStorage 队列；断网编辑可等待重连。已连接时的文字输入草稿尚未保存入队，关闭页面会丢失。正在编辑的对象被他人删除时禁止保存，但保留输入框供复制。
- JSON 导出升级为 schemaVersion 2，包含 strokes 和 objects。没有导入功能；导出不含房间凭证。
- 上限：每房间 500 个文字/便签、10,000 次对象命令、单对象 500 代码单元；笔迹原上限不变。命令收据不压缩，快照存储与限额均属于试用阶段。

笔迹绘制在文字与便签上方，可用画笔进行标注；笔迹与便签仍是独立内容，移动便签不会携带笔迹。当前工具不提供分组或图层重排。长文本使用固定宽度排版，实际字体回退仍需 Android WebView 真机确认。

## 验证入口

- npm test：真实 WebSocket 创建、输入预览、只读权限、字段合并、重复操作、删除后迟到操作、服务重启恢复；核心输入校验、换行/emoji 与总览范围。
- npm run build：TypeScript 与网页/服务生产构建。
- npm run test:e2e：文字/便签新增、输入法组合事件防误提交、拖动预览、取消、离线修改、刷新恢复、导出、手机布局和编辑中远端删除；同时回归原有五个场景。

自动化输入法事件不等于真实中文软键盘验收。电视硬件、Safari、压感笔、10 人容量和多小时稳定性仍待执行。既有 0.2.0-preview APK 无需重建，连接新版服务并重新加载页面即可使用此次网页能力。
