# 电视控件、二维码与画布范围

更新：2026-11-23。根据真机使用反馈调整电视交互，新旧电视页面保持一致。

## 按钮状态与动画

电视控件不再使用蓝色外框表示遥控器焦点。焦点采用浅色底与柔和阴影；当前视图按钮采用填充底色和 `aria-pressed`，明确区别“遥控器当前落点”和“正在使用的视图”。顶部邀请主按钮获得焦点时也保持填充状态，移除其蓝色细边。焦点与按下采用约 200 ms 的颜色/阴影过渡，不移动按钮本身。

二维码面板以约 240 ms 的透明度及轻微位移/缩放展开收起，展开方向向上。现代与 WebView 66 电视镜头都使用逐帧插值，视图切换、面板宽度变化、关注指针时不会直接跳到新镜头。遵循 `prefers-reduced-motion`，开启减少动画时直接切换。

## 固定二维码入口

“显示加入二维码 / 收起二维码”为同一个持久按钮，固定在右下角视图按钮组上方。二维码内容定位在按钮上方，展开或收起均不改变按钮坐标、尺寸、焦点和 DOM 元素身份。关闭后隐藏内容退出遥控器焦点导航；再次展开后保持原加入方式，手机管理仍在二维码面板内部。

二维码折叠后释放右侧画布预留宽度；显示时为二维码预留空间。旧电视在 CSS 960×540 下保留顶部及底部控件空间，二维码面板、固定按钮和视图按钮组互不重叠。

## 三种视图职责

| 控件 | 含义 |
| --- | --- |
| 完整画布 | 默认展示世界坐标 (0,0) 到 (1280,720) 的画布范围，包含未书写区域 |
| 显示全部内容 | 根据实际图文、笔迹及当前过程预览计算包围范围，排除默认空白区域 |
| 关注成员 | 单独选择/循环在线编辑成员，跟随其指针；不会改变其他设备视角 |

默认进入完整画布。内容超出默认范围时，完整画布以 1280×720 为单位向外扩展到整块边界，保证越界内容仍可展示；它不等同于紧贴内容的包围框。小范围内容时两种模式的显示比例明显不同。空白文档的“显示全部内容”回退到默认画布；内容刚好铺满整个范围时，两种视图可以接近，这是预期行为。

点击完整画布或显示全部内容都会退出成员关注，并更新活动按钮状态。`F` 快捷键对应显示全部内容。编辑端的原“适配全部内容”也统一更名为“显示全部内容”，编辑端个人镜头逻辑保持独立。

## 实现与验证

- core：默认范围与向外扩展规则。
- BoardEngine / legacy-tv：明确区分 canvas、content 和 member 状态，镜头平滑切换。
- TVJoinCard / legacy-tv.html：固定二维码按钮和绝对定位的内容面板。
- 样式：按钮填充状态、焦点阴影、折叠动画与减少动画支持。
- 浏览器专项用例覆盖：两种接收页面重复开关二维码、按钮位置/焦点不变、二维码在按钮上方、按钮在底部控件上方、无焦点外框、两种画布范围不同、镜头中间动画状态及返回恢复。

本轮仅更新网页资源，不修改房间内容或要求重装 APK。当前内网电视自动重载后生效，其他已打开页面需刷新。形状、连线与协作撤销仍为后续功能，本轮集中完成交互修订。
