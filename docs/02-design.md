# 交互与视觉规范

采用低干扰的白板工作界面。电视提供公共视野，手机与 Pad 提供精准操作；视觉以内容为中心，不复刻飞书品牌资产。

## 页面与状态

| 页面 | 关键内容 | 主要动作 |
| --- | --- | --- |
| 电视启动 | 最近白板、创建入口、网络状态 | 创建、恢复 |
| 电视房间 | 全屏画布、轻量房间状态、成员指针 | 显示二维码、总览、聚焦、结束 |
| 手机加入 | 房间名称、昵称、权限与连接提示 | 加入、重新扫码 |
| 手机编辑 | 画布、底部工具、上下文属性栏 | 编辑、撤销、定位电视区域 |
| Pad 编辑 | 画布、侧边工具、选中对象属性 | 双手操作、触控笔绘制 |
| 主持人面板 | 成员、邀请、电视镜头、保存 | 管理、聚焦、导出 |

每个页面提供加载、空白、正常、断网重连、权限失效、房间关闭和错误状态。不能用永久加载动画掩盖失败。

## 电视布局

默认画布覆盖屏幕。房间信息和在线人数使用轻量覆盖层；二维码只在无人加入时或主动召唤时扩大展示，有人加入后收起为角落入口。所有覆盖层都计入画布适配的遮挡区域。

遥控器确认键唤出菜单，方向键移动焦点，返回键先退出菜单或聚焦模式；退出房间需要明确确认。电视可以完成最基本的创建、显示二维码和返回总览，不依赖触摸屏。

焦点、成员身份与连接状态不能只依靠颜色表达。指针使用颜色、昵称、轮廓；重名添加短后缀。多人靠近时降低非活动标签密度，触摸结束短暂淡出指针，保留成员在线状态。

## 编辑手势

- 画笔模式：单指/笔绘制，双指平移与缩放；双指开始时取消未确认的误触草稿。
- 选择模式：点击选择，拖动选中对象，空白区域拖动平移；框选提供显式工具。
- 文字模式：点击创建 DOM 文本输入层，输入法组合结束后确认；组合过程不提交半成品汉字。
- 图片：上传过程中显示占位与进度，失败允许重试；上传完成后同步资产引用。
- 触控笔压力是增强能力；不支持时使用固定宽度。防误触需真机验证，网页不能承诺系统级手掌拒绝。
- 撤销按钮只撤销本人的内容操作，视角移动不进入文档撤销栈。
- 手机软键盘出现时移动编辑区域，避免文本被遮挡。尊重安全区和屏幕旋转。

## 初始视觉变量

| 用途 | 基线 |
| --- | --- |
| 画布 | #F7F8FA，轻量点阵，可关闭 |
| 面板 | #FFFFFF，细描边 #E2E6EC，圆角 12px |
| 正文 | #172033；次级信息 #596579 |
| 强调色 | #315EFB，主要按钮与选中焦点 |
| 成员色 | 蓝、紫、青、橙、玫红；同时提供名称与轮廓 |
| 手机字号 | 正文 16px，辅助 13–14px |
| 电视字号 | 1080p 基线控制文字 24–32px，实际观看距离验证 |
| 触控目标 | 至少 44×44 CSS px，主要工具优先 48px |
| 动效 | 面板 120–180ms；镜头 250–400ms，支持减少动态效果 |

画布上的文档字号与界面字号分开。总览缩放后的可读性通过分区、聚焦和布局解决，不能通过放大界面文字解决。
