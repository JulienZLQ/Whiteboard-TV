# 协作撤销、图片导出与电视方向导航

本轮延续 M3 基础编辑，推进协作撤销/重做、PNG 导出及用户反馈的右下角遥控操作。脑图属于下一阶段。

## 电视操作

右下角底行按“管理成员、完整画布、显示全部内容”排序。上行为固定二维码按钮。上下键切换两行，左右键只移动当前行；到边缘后停留，避免横向移动时跳到另一组。上行返回下行时保留原列。焦点仍使用按钮底色、阴影及自然过渡，不添加蓝色外框。二维码展开/收起不改变按钮位置。

管理成员打开成员面板，原有关注成员能力移入该面板。现代电视上的主持人可以直接管理会话，普通观看端仅查看/关注成员；旧电视提供成员关注与手机认领主持的二维码入口。返回关闭面板并恢复入口焦点。关注只影响当前电视。

显示全部内容按实际内容边界适配，删除固定边距和 1.5 倍放大上限，在不遮挡内容的可用矩形中尽量放大。可用区域根据实际顶部控件、二维码及底部两行按钮计算；不额外添加安全边距。等比显示时，内容与屏幕宽高比不同的一轴仍自然留空，不裁切内容、不拉伸。完整画布保持默认 1280×720 并按整块向外扩展。

## 撤销与重做

编辑端提供撤销/重做按钮，支持 Ctrl/Command Z、Ctrl/Command Shift Z、Ctrl Y；文本输入框保持原生文字撤销。一次笔迹提交、对象创建/删除、文字保存、拖动完成、尺寸调整或端点调整为一个历史步骤。整条擦除以每条被擦笔迹为一步。

每个个人凭证保留最近 50 步；同一凭证的标签页共享历史，其他参与者有独立历史。同一浏览器会话刷新、断网重连、服务重启后仍能恢复。新编辑会清除自己的重做分支。只有在线且本机命令全部保存后才允许开始撤销；已经发出的撤销在断线重连时使用同一操作 ID 重试。

服务端在房间串行队列中计算逆操作并检查字段版本。位置、尺寸、文字、连线几何分别校验；撤销移动不会覆盖其他人后来调整的尺寸。创建/删除校验整个对象的版本；删除目标及相关连线解绑作为同一个历史步骤，撤销时一起恢复。

如果同一字段已被后续操作写入，即使值相同也不会覆盖。遇到冲突时跳过该步、提示原因；若撤销新建对象会使别人的新连线悬空，也跳过。恢复时检查对象/笔迹/点数容量。历史及版本与文档写入同一个原子文件快照，保存失败不推进文档和历史。所有新增持久命令有操作 ID 去重，重复收到撤销确认或跨重启重试不会多撤一次。

历史条目独立保存，栈只保存引用，避免每一步重复复制整段笔迹历史。当前仍使用 Y.Doc 文件快照，房间最多 10,000 个新持久命令；容量与长时性能尚需专门验收。历史只从升级后的操作开始记录，不追溯旧操作。

## PNG 导出

手机/Pad/桌面编辑端可选择“导出完整画布”或“导出全部内容”，原 JSON 副本入口保留。PNG 为白色背景，包含已提交或本机待提交的笔迹、文字、便签、图片、形状及解析后的连线；不包含工具栏、选择框、指针和其他人的临时预览。

绘制顺序保存在文档中，删除撤销保留原有层次；不同设备从 Y.Doc 恢复后按同一顺序叠放对象和笔迹。旧对象没有顺序记录时采用一致的 ID 排序。导出复用编辑器的对象绘制实现，在独立画布渲染，不改变个人或电视镜头。图片鉴权读取并完整解码后才导出；任意图片失败则提示重试，不静默输出缺图版本。最长边 4096 像素、总像素不超过约 800 万、最高 2 倍世界坐标分辨率，以控制手机内存。极大白板会缩小，不保证小字仍可阅读；后续可增加分区/分页输出。

## 实现与验证入口

- `apps/server/src/history.ts`：历史条目、字段版本、条件逆操作与引用完整性。
- `apps/server/src/server.ts`：鉴权、串行队列、原子保存及历史状态广播。
- `apps/web/src/session.ts`：历史状态和操作重试。
- `apps/web/src/canvas/object-node.ts`、`canvas/export.ts`：共用绘制及独立 PNG 输出。
- `apps/web/src/tv-layout.ts`：按行遥控导航、无额外边距适配。
- `components/Board.tsx`、`RoomControls.tsx`、`legacy-tv.ts`：双电视入口与编辑端控件。

验证：`npm test`、`npm run build`、`npm run test:e2e`。浏览器工具仍为已有 Playwright Chromium（Browser plugin not available）。验收完成后追加实际结果。
