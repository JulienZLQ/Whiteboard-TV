# 形状、箭头与对象连接

更新：2026-11-23。本轮推进 M3 基础编辑，不将脑图或协作撤销计为完成。

## 用户流程与视觉

编辑端的颜色栏增加“形状与连线”入口，展开后选择矩形、椭圆、箭头或连线。桌面面板出现在工具栏旁，手机面板出现在缩放控件和底栏上方；面板展开时隐藏当前对象操作条，选择后自动收起，拖动绘制。形状支持正向/反向拖动，单击放置默认大小；完成后回到选择工具。

矩形与椭圆采用当前画笔颜色、轻填充与 3 世界单位描边。选择后可以移动、拖动右下角调整宽高，或通过缩小/放大按钮等比调整。图片保持原有等比缩放。形状本轮不包含内部文字；可使用文字工具另行放置标签。

箭头与连线在对象上开始/结束时自动连接，支持连接矩形、椭圆、文字、便签与图片。端点根据目标当前几何位置计算到边界；移动/缩放目标或收到实时预览时，连接同步跟随。选中连线可拖动两个端点重新连接；拖动整条线会解除两端绑定，变成自由线。

电视继续只读显示整个画布、全部内容或成员关注，二维码固定位置和按钮状态沿用上一轮。新对象在现代 Konva 页面与 WebView 66 Canvas 2D 页面显示，绘制过程通过现有临时对象预览通道传播。

## 数据与同步

- `ShapeObject`：`kind: shape`、`shape: rectangle | ellipse`、x/y、width/height、color。尺寸 16–4000 世界单位，使用现有对象数量上限。
- `ConnectorObject`：`kind: connector`、起点 x/y、相对向量 dx/dy、`fromId`/`toId`（可为空）、arrow、color。自由线支持任意方向；两个端点均受坐标上限校验。
- 对象移动和尺寸仍分字段提交，互不覆盖；端点与两个绑定 ID 作为一个几何字段组提交，保证一次端点修改完整。相同字段并发操作由服务端最后持久化结果决定。
- 绑定只允许同房间、非连线对象；服务端将不存在或不合适的绑定归为空端点。禁止自连接和两端连接同一对象。连线不作为连接目标，不构成递归几何。
- 删除目标时，服务端在同一持久化事务中计算连接当时的显示端点，解除涉及该目标的一端并保留位置；另一端继续跟随。删除墓碑阻止迟到操作复活目标。
- 离线创建、移动、缩放与端点调整复用本地待提交队列。临时预览不替代最终保存；双指手势或指针取消不提交未完成对象。
- 含形状或连线的导出升级为 JSON v4；有图片时仍携带引用的 PNG 数据。仅有图文保持此前 v2/v3。导入、PNG 导出仍待开发。

## 实现位置

核心类型、边界、线段命中、矩形/椭圆连接端点计算与补丁校验在 `packages/board-core/src/index.ts`。服务端串行校验、引用归一化与删除解绑在 `apps/server/src/server.ts`。编辑端绘制、拖动、调整和渲染在 `canvas/engine.ts`；工具面板在 `components/Toolbar.tsx`；旧电视绘制在 `legacy-tv.ts`。

不增加运行时依赖或修改 APK。部署需要更新服务器与网页，并刷新旧编辑页面和电视接收页面：旧版网页不认识新增对象类型。文件快照保持兼容，无破坏性数据迁移。若回滚，含新对象的房间应使用本轮网页和服务读取，不直接交给旧编辑器。

## 验证计划

- 核心：形状尺寸/坐标、非法绑定、自由线方向、矩形/椭圆边界连接、线段命中、视图范围。
- 服务端：多人同时移动/缩放、只读电视、实时预览、错误种类补丁、删除后解除连接、跨文档引用、重试/墓碑与重启恢复。
- 浏览器：绘制过程同时到达两种电视、移动/缩放时连接跟随、删除解绑、端点调整、刷新恢复、手机面板、反向绘制、双指取消、离线保存。
- 视觉：桌面、手机、现代电视与真实旧电视的页面身份、非空画布、无错误覆盖层、控制台、截图及控件位置。

实际执行结果在完成验收后追加；容量、Safari、真实触控笔与多小时运行仍独立跟踪。
