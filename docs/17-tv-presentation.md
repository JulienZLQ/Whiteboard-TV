# 电视展示界面与遥控交互

2026-11-23，Android TV 0.2.2-preview。适用于现代电视网页与 WebView 66–109 兼容画布。

## 布局与行为

- 右上角依次为实时同步、实时连接、管理成员、设置，四个控件各自使用独立圆角底板。两个状态使用不可聚焦的状态标签，仅管理成员、设置进入遥控焦点顺序。成员关注和主持管理集中在管理面板，现代页面的邀请链接也保留在该面板内。
- 左下角“隐藏界面”淡出控制层，包括标题、状态、二维码、视图控件和空白提示；仅保留“显示界面”按钮。画布、协作内容及指针继续显示，实时连接不受影响。再次点击恢复控制层以及原来的二维码展开状态。
- 隐藏时，镜头使用整个屏幕进行等比适配，不额外预留控制栏空间。“完整画布”仍以默认 1280×720 整块范围为依据，“显示全部内容”仍使用真实内容范围；二者不会合并成同一个模式。显示全部内容没有额外固定边距。
- 右下角仅保留完整画布、显示全部内容。遥控器焦点进入其中一个按钮立即选择对应视角，不需要确认；镜头持续平滑过渡。
- 二维码开关仍固定在视图控件上方，面板向上展开。获得焦点即纯蓝底、白色文字，确认键直接切换。按钮颜色与阴影有自然过渡，不使用蓝色焦点外框。
- 上下在右上控件、二维码、视图控件之间移动；左右在同排移动。完整画布再向左可到隐藏界面，隐藏界面向右返回视图行；回到视图行记住原列。隐藏控件不会再接受遥控焦点。

## 设置与返回

右上角设置与遥控 MENU 调用同一个 Android 原生菜单：继续展示、重新加载、新建白板、服务地址设置、退出应用。

返回先关闭最上层成员/邀请/设置弹窗；在主画布上返回显示“退出白板？”确认，默认选中“继续展示”。选择退出才关闭 Activity，不结束协作会话。再次打开恢复原房间。设置菜单中的退出应用也使用同一确认。

未增加 JavaScript 原生接口。新 APK 用专用 User-Agent 标识自身；网页设置按钮请求同源保留路径 `/__whiteboard_tv__/menu`，原生仅拦截同源主框架该路径并打开菜单，页面不会离开当前房间。其余来源和资源限制保持原有策略。

普通浏览器电视模式提供网页菜单与离开白板确认，退出回到白板首页；浏览器不提供 Android 服务地址设置。新版网页需配合 0.2.2-preview APK 使用原生设置按钮及新的返回行为。

## 独立按钮与等宽视图组修订

右上角取消共同底板，状态标签和操作按钮之间使用独立间隔；采用相邻元素外边距兼容 WebView 66 不支持 flex gap 的情况。右下视图组与二维码开关使用同一个宽度变量：兼容电视 232 CSS px、现代网页 208 CSS px；内部两项等宽，不受标签字数影响，移除中间占宽分隔线。

本次类型检查、生产构建和两项电视浏览器专项回归通过。1920×1080 现代页面与 960×540 兼容页面实测四个独立控件、两个不可聚焦状态、两组外边界同宽对齐、内部选项等宽、文字无溢出及隐藏/恢复通过，无控制台错误。真实 MiTV-ASTP0 实测二维码与视图组同为 232 CSS px、两项各 111 CSS px，原生方向键跳过两个状态，管理成员和设置均可打开。已更新内网页面并恢复原房间，APK 维持 0.2.2-preview，用户内容保留。


## 滑动高亮与创建页导航修订

右下两项改用同一块蓝色滑块，通过 transform 在两项之间平移，320 ms 缓动；快速反向从当前位置接续，文字颜色同步过渡。关注成员时隐藏视图滑块，减少动态效果设置下取消动画。右上四个独立控件统一为 120 CSS px，两个状态仍不可聚焦。

修复兼容电视创建页的焦点陷阱：原先设置向下只寻找画布页的二维码或视图行，创建页没有这些目标；现在创建按钮加入 welcome 导航行，设置向下到创建，创建向上回到设置，确认键正常创建。初始焦点仍在创建按钮。

本轮 TypeScript、生产构建与 4/4 电视专项回归通过；回归覆盖设置与创建之间两次往返和确认创建。现代/兼容浏览器验证共享滑块中间帧、反向接续、减少动画偏好、顶部等宽及无溢出；真机 WebView 66 记录到 18 个滑块中间帧，管理成员和设置可正常使用。Browser plugin not available，使用既有 Playwright 与 ADB 验证。内网服务已保留数据并更新，APK 无需重装。

创建按钮状态补充：现代与兼容电视创建页的主按钮未聚焦时为白底深色文字，仅聚焦时变为蓝底白字；移出焦点平滑恢复白色，悬停本身不会保持蓝色。减少动画偏好下关闭颜色过渡。
