# M2 第一批：电视扫码与主持管理

更新：2026-11-23。用户确认按通用 Android TV / 安卓盒子开发。本批交付浏览器闭环，不等于 APK 或 M2 全部验收完成。

## 使用流程

1. 电视打开服务地址的 `/?mode=tv`，选择“创建电视白板”。也可在首页勾选电视创建模式。
2. 电视右侧显示编辑二维码，手机/Pad 扫码、填写称呼后独立书写。二维码可收起，顶部邀请入口可重新打开。
3. 创建者具有主持权限。电视“管理 → 手机认领主持权限”展示专用一次性二维码，由主持人用手机扫码。它不同于普通编辑二维码；认领后电视仍保留管理能力。
4. 主持人可以暂停/恢复新成员加入、更新二维码、移除编辑成员、结束会话。结束前有明确二次确认。
5. 电视底部可选择关注某位编辑成员，按其指针平滑跟随；选择完整画布或点击适配按钮返回总览。

真实扫码要求电视、手机可访问相同服务地址。默认回环地址只能本机演示；本次没有开放 NAS 或部署公网服务。二维码图像和邀请链接内容相同，浏览器测试使用链接验证加入流程，物理摄像头扫码仍需真机验证。

## 权限与邀请

- 普通邀请有效期 12 小时，由服务端验证，不依赖客户端倒计时。重连使用个人凭证，不再使用已消费的邀请链接。
- 每次普通邀请加入签发独立随机编辑凭证，在当前标签页 sessionStorage 保存；刷新可恢复。创建者凭证带主持权限。
- 主持认领码成功使用一次后失效；更新邀请可以生成新的认领码。只向已有主持人发送认领码，不向普通编辑者或电视观看凭证发送。
- 暂停只阻止使用邀请和认领码加入；已有个人凭证仍可重连、编辑。
- 更新邀请使旧邀请和未消费认领码失效，现有个人凭证继续有效。
- 移除使该个人凭证失效，断开使用该凭证的全部连接，并轮换邀请，防止通过旧链接立即回来。能再次看到新二维码的人仍可重新申请加入；目前没有账户级封禁或人工准入。
- 结束永久关闭当前会话接入，断开全部设备，保留磁盘快照；尚无“重新开放”或归档列表。客户端可继续导出已接收内容与本地待保存副本。
- 电视显示模式不能提交笔迹，主持身份与编辑/观看模式分别校验。普通观看设备可以展示当前编辑邀请，这是电视扫码产品行为。
- 管理、邀请兑换和笔迹保存使用同一房间串行队列；元数据写入成功后广播和踢人；移除/结束之后的排队操作不回灌。
- 老 M1 房间按原创建凭证迁移为主持凭证。老版本曾共享创建凭证，旧持有人可能都有主持权；正式试用应新建 M2 房间。

实验限制：每房间最多 32 个同时连接、256 个有效个人编辑凭证，64 个加载房间；无账号、跨实例广播和后台归档清理。这些限制不是已完成容量压测的证明。

## 电视镜头与视觉

沿用 M1 点阵画布、浮动白色面板和蓝色主按钮。新增电视加入卡片、独立会话管理弹窗和成员关注选择器；移动端主持界面压缩品牌区域以避免顶部重叠。

总览初始范围为 1280×720；后续合并已保存笔迹和实时草稿包围盒，只向外扩张，不因抬笔、草稿清理或擦除反复放大。超出范围时使用时间相关的平滑插值；短暂过渡期间新内容可能仍处于画面外。手动适配收紧范围。大屏总览为右侧二维码预留 270px，减少画布遮挡；收起二维码后仍保留该空白，以免镜头跳动。遵循系统减少动态效果设置。

关注模式只影响当前显示设备，尚未实现手机主持人远程控制电视关注目标。无指针或成员离开时回到总览。遥控器空间导航、WebView 版本兼容和电视安全边距仍需 APK 阶段验证。

## 协议增量

- hello 可带 viewOnly，服务端在鉴权后将当前连接限制为观看。
- ready 返回个人 token、host、access；客户端将邀请替换为个人凭证。
- access 包含 inviteToken、expiresAt、paused、ended；主持连接另有 claimToken。
- manage 支持 pause、resume、rotate、remove(memberId)、end，所有权限在服务端检查。
- 持久化 access 元数据与 Yjs 快照在同一个原子文件写入；继续使用文件快照，尚未迁移 PostgreSQL。

单元/服务端集成：8 项通过。新增真实 WebSocket 用例覆盖个人凭证、非主持拒绝、暂停后旧成员重连、轮换、撤销所有同凭证连接、一次性认领、过期校验、结束会话及服务重启后仍拒绝接入；同时验证快照保留。

浏览器集成：4 项通过（33.5 秒）。覆盖原有三端协作、断网恢复、双指取消误触，以及电视创建→手机编辑→镜头稳定→成员关注/返回总览→暂停/恢复→移除与刷新后拒绝→手机认领主持→结束会话。构建与 TypeScript 检查通过。测试环境为 Playwright Chromium；Browser plugin not available。继续复用工作目录图形库与字体，无系统库修改。截图检查 1920×1080 电视、1024×768 Pad、390×844 手机与主持管理弹窗，页面标题正确、非空、无错误覆盖层、无 pageerror/console warning/error，手机无横向溢出。临时验证服务已停止。

尚未验证：真实 Android TV、遥控器、手机摄像头扫码、Safari/触控笔、10 人负载、4 小时运行、服务端磁盘故障注入。尚未实现：APK、文字/便签、贴图、脑图、账户、数据库增量存储、HTTPS 部署。
