# 共创白板 · 共写视觉标识

用户选定 01「共写」，最终采用精确重绘的 SVG 母版。蓝色画布与蓝色、浅紫色两笔相向书写，左右边框各有一处贯穿的白色断口。所有延展必须保留这些断口和笔画中间的留白，不可补成闭合边框。图标铺满正方形，四角透明，无外围白色底板、阴影或额外留边。

## 颜色与资产

- 主蓝 #315EFB；协作浅紫 #9AA7FF；内部白色 #FFFFFF。
- 电视封面深蓝 #172B61，白色产品名称，图标保持原色。图标与背景有区分，缩到 320×180 仍能辨识。
- 欢迎页底色 #F7F8FA，装饰笔画 #E1E8FF / #ECE9FF；横、竖版分别排布，不把装饰铺到实际协作画布。
- 矢量源文件位于 assets/brand：co-write-icon.svg、tv-banner.svg、welcome-background.svg、welcome-background-portrait.svg。

| 使用位置 | 实现 | 约定 |
| --- | --- | --- |
| 网页、手机、兼容电视页标识 | public/brand/co-write-icon-v1.svg | 装饰图片 alt 为空，旁边保留真实文字产品名 |
| 欢迎页 | 横、竖版 SVG 背景 | 竖屏按宽高比切换，创建后隐藏兼容页背景 |
| 浏览器标签页 | 32 px PNG | 从母版导出，避免旧浏览器 SVG favicon 差异 |
| 手机添加到主屏幕 | 180 px PNG | apple-touch-icon；未声称提供离线 PWA |
| Android 原生加载页 | app_icon.xml | 直接复制母版路径，无轮廓近似或 AI 重画 |
| Android 桌面 | AdaptiveIconDrawable | 相同路径放在 108 单位层的 72 单位可见区域；蓝色背景适应启动器遮罩；包含单色主题层 |
| Android TV 应用封面 | drawable-nodpi/tv_banner.png | SVG 导出为标准 320×180，中文名称已栅格化，不依赖电视字体 |
| 原生连接／加载界面 | welcome_background.xml | 与横版 SVG 相同曲线路径，低对比背景 |

SVG 封面中的产品名保持可编辑文字，导出字体为 WenQuanYi Micro Hei；不同电脑编辑 SVG 时可安装兼容中文字体或换用产品字体。已经导出的 PNG 与电视 APK 不依赖该字体。未打包或分发字体文件。

## 更新规则

先改 assets/brand 母版，再同步 public/brand 与 Android VectorDrawable 的路径和颜色。封面和背景只引用同一组图形语言，不另生成一套标志。更新静态资源时使用新版本文件名，避免终端缓存保留旧标识。

实际白板只更新左上标识，画布坐标、绘制内容、指针和导出图片均不加入品牌背景。欢迎页背景只用于进入前的页面；隐藏界面操作会继续隐藏左上标识。
